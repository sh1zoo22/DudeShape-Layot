# DudeShape-Layot

DudeShape — Adaptive Layout
Современный и адаптивный макет, выполненный с использованием актуальных практик верстки. Проект демонстрирует навыки работы с гибкими контейнерами и медиа-запросами.

📱 Демонстрация
Посмотреть проект: [https://sh1zoo22.github.io/DudeShape-Layot/]

🛠 Технологии и подходы
В этом проекте я сфокусировался на гибкости и чистоте кода:

HTML5: Семантическая разметка для лучшего SEO и доступности.

CSS3 Flexbox: Основной инструмент для построения сетки и выравнивания элементов.

Mobile First (или Desktop First): Адаптивность реализована через Media Queries для корректного отображения на смартфонах, планшетах и ПК.

🔧 Особенности разработки
Я придерживаюсь принципа прозрачности в разработке, поэтому выделяю текущие моменты:

Адаптивность: Сайт корректно перестраивается под разные разрешения экрана благодаря Flexbox.

Работа над ошибками (Work in Progress): * В коде присутствует использование position: absolute, которое в редких случаях может вести себя нестабильно.

В планах: Провести рефакторинг этих участков, заменив их на более устойчивые решения (Grid или дополнительные Flex-контейнеры), чтобы обеспечить 100% стабильность на всех устройствах.
